Amhaz Services

تصميم بنفسجي موحد لكل الصفحات، فاتح وداكن.
كل قسم بالرئيسية له عنوان وصف مستقل للخدمات، مع تمرير أفقي إذا زادت.
التنقل المباشر للتفاصيل فقط عندما يكون العنصر الوحيد unit=balance أو validity.
الخدمات الأخرى تعرض قائمة مهما كان عدد عناصرها.
واجهات API ومنطق الإرسال والأسعار والإشعارات لم تتغير.
ملف app-navigation.js غير الموجود أزيل استدعاؤه فقط.

التركيب: انسخ محتويات هذا المجلد فوق ملفات واجهة الزبائن بالموقع نفسه، ثم حدّث المتصفح بـ Ctrl+F5.
هذه واجهة HTML وليست سيرفر مستقل.

التحقق: فحص صياغة JavaScript ومقارنة كود API والطلبات واختبار شرط التنقل وزر الثيم ببيانات محلية تجريبية.
المعاينة البصرية بالمتصفح لم تتوفر في بيئة العمل، ولم يتم إرسال أي طلب حقيقي.
